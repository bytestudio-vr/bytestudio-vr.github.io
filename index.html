Why it feels native

A remote desktop built for VR, not a window in space

Move, resize and recenter your desktop around you. Passthrough keeps your hands, keyboard and room visible. Rendering, input and connection handling are tuned for everyday work, not just a demo.

🖥️

Readable at panel size

Resolution adapts to the number of screens, up to 1600×900 for one screen. Hardware H.264 decoding is used when the host supports it.

👁️

Passthrough by default

Your hands, keyboard and room stay visible around the desktop. Dim the room independently for focus; your brightness setting is remembered.

🖱️

Stabilized pointer

Filtering and dual-hand arbitration keep the cursor precise. Drag windows across screen seams in one gesture; resizing a panel does not move the remote cursor.

⌨️

Keyboards that work

Use a Bluetooth keyboard or open the headset keyboard with A/X or the dock. Typed paste stays tied to its original session when you change connections.

🔊

Responsive video and audio

Video presentation runs separately from network reads, so drawing a frame does not hold up incoming desktop audio. Playback still depends on your host and network.

🔒

Direct and pinned

An encrypted RDP connection straight to your PC. The server certificate is pinned on first use, like SSH.

Up and running

Three steps to your desktop

No sideloading and no Developer Mode. The app comes from the Meta Horizon Store.

Install from the Store

Get ByteStudio Remote Desktop on your Quest from the Meta Horizon Store. It installs like any other app.

Enable Remote Desktop on your PC

Windows: enable Remote Desktop in System settings on Server or a Pro / Enterprise desktop edition.
GNOME: Settings → System → Remote Desktop (or Sharing on older versions). Choose Remote Login for multiple screens, or Desktop Sharing for one.
Other Linux desktops need an RDP server such as xrdp. Note the host's IP address and RDP port.

Connect from the headset

Enter the host address, port and RDP credentials. The app shows startup progress and keeps the form visible until the first desktop image is ready. Then move, resize or recenter your panels.

Before you start

Requirements & limits

What you need

  • Meta Quest 3 or Quest 3S
  • A Windows or Linux RDP host; check the compatibility table above
  • The headset and the PC on the same local network
  • Ethernet or Wi-Fi 6 recommended for smooth video

What to expect

  • Screen count and live changes depend on the host, not just your edition
  • A reconnect may be needed for a screen-count change and can rearrange remote windows
  • Video frame rate and audio continuity depend on the host and network
  • The host must offer audio redirection; xrdp may need an audio module
  • Clipboard sharing is text only; there is no file transfer
  • A network drop ends the session; reconnect from the app

Clear status, without unnecessary interruptions

A slow desktop startup or screen-layout confirmation is shown as a wait, not treated as a failure. Notifications below the dock keep active waits and errors visible, with Details for longer diagnostics. You can keep working while a layout request is pending, or choose Connection → Reconnect after the interruption warning.

Questions

Good to know

Is the app free?

Yes. The free edition is a complete remote desktop with up to two flat screens, subject to host support. Ultra is a one-time purchase made inside the app, with no subscription.

What exactly does Ultra add?

A third screen, curved panels and layout presets. You can switch between flat and curved in the app settings; the choice is remembered and applied on the next launch.

How do I buy Ultra?

Install the free app, open the connection form and use the Ultra card. The purchase is handled by the Meta Horizon Store and stays attached to your Meta account.

Do I need Developer Mode or a sideloaded APK?

No. The app is distributed through the Meta Horizon Store and installs like any other Quest app.

Does it work with Windows?

Yes. Windows Server 2025 has been tested on Quest 3 with one to three screens and screen-count changes without reconnecting. Windows 10/11 Pro or Enterprise can host RDP, but these desktop editions have not yet been tested here. Windows Home cannot host RDP. See the compatibility table for the scope of testing.

Which Linux desktops work?

GNOME Remote Desktop on Ubuntu is the reference setup tested on Quest 3. Remote Login supports multiple screens; Desktop Sharing mirrors one screen. xrdp 0.9.24 with Xorg has been verified with one to three screens at connection, but changing the screen count requires a reconnect in the tested setup. Initial multi-screen support does not require live Display Control. Other servers and versions are not automatically covered by these tests.

Can I add or remove screens while connected?

Use the minus and plus controls in the dock, within your edition's limit. GNOME Remote Login and Windows Server 2025 have been tested with live changes. A slow confirmation keeps the desktop usable; waiting alone does not trigger a reconnect. If the change is unavailable or interrupts the connection, the app explains the fallback and reconnects once with the requested screen count. You can also choose Connection → Reconnect, with a warning that it interrupts the session.

Why does the app say Desktop starting…?

Signing in and showing the first desktop image are separate steps. GNOME Remote Login can take around ten seconds to start a session. The connection form stays visible until an actual image has been presented, rather than exposing a blank panel. Waiting messages, errors and reconnect notices appear below the dock; use Details for longer diagnostics.

What if accents appear as Unicode escapes in the clipboard?

Text is preserved exactly by default, including literal escapes in code and JSON. Some GNOME server versions escape accented characters. For an affected host, open Compatibility and enable Decode clipboard Unicode escapes; the choice is remembered for that address and port. It applies only to text received from the server and can alter literal escapes, so leave it off on unaffected hosts. It does not repair the headset-to-server direction; that needs a server-side fix. Clipboard sharing is text only.

Where does my data go?

The connection goes straight from the headset to your PC. There is no account and no cloud relay. The server certificate is pinned on first use, and the connection credentials stay on the headset, encrypted.

Can I go back to the flat layout after buying Ultra?

Yes. Ultra includes a switch between curved and flat panels. Nothing is locked in one shape.

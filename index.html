Up and running

Three steps to your desktop

No sideloading and no Developer Mode. The app comes from the Meta Horizon Store.

Install from the Store

Get ByteStudio Remote Desktop on your Quest from the Meta Horizon Store. It installs like any other app.

Enable Remote Desktop on your PC

Windows 10/11 Pro or Enterprise: Settings → System → Remote Desktop, turn it on. Home editions cannot host RDP.
Linux: GNOME Settings → Sharing → Remote Desktop, turn it on and set a username and password.
In both cases, note the PC's local IP address.

Connect from the headset

Open the app, enter the IP address, username and password, then connect. Your desktop appears as a panel you can move and resize.

Before you start

Requirements & limits

What you need

  • Meta Quest 3 or Quest 3S
  • Windows 10/11 Pro or Enterprise with Remote Desktop enabled, or a Linux RDP host
  • The headset and the PC on the same local network
  • Ethernet or Wi-Fi 6 recommended for smooth video

What to expect

  • Any standard RDP server; Ubuntu GNOME is the reference setup we test against
  • Windows 10/11 Pro is expected to work and to expose Display Control, but it is unverified
  • On Linux, multi-screen depends on the host exposing Display Control
  • Frame rate follows the host, around 30 fps on GNOME
  • Clipboard sharing is text only; there is no file transfer
  • A network drop ends the session; reconnect from the app

Windows is experimental for now

The app speaks standard RDP, and Windows 10/11 Pro or Enterprise exposes an RDP server, so it is expected to work. We have not officially tested Windows yet, so treat it as experimental until it is validated. If you try it, tell us what happened — Windows version, app version, and whether the third screen appeared: bytestudio.rdp@gmail.com.

Questions

Good to know

Is the app free?

Yes. The free edition is a complete remote desktop with two flat screens. Ultra is a one-time purchase made inside the app, with no subscription.

What exactly does Ultra add?

A third screen, curved panels and layout presets. You can switch between flat and curved in the app settings; the choice is remembered and applied on the next launch.

How do I buy Ultra?

Install the free app, open the connection form and use the Ultra card. The purchase is handled by the Meta Horizon Store and stays attached to your Meta account.

Do I need Developer Mode or a sideloaded APK?

No. The app is distributed through the Meta Horizon Store and installs like any other Quest app.

Does it work with Windows?

In principle, yes, but Windows is not officially supported yet because we have not tested it. Windows 10/11 Pro or Enterprise exposes a standard RDP server: enable Remote Desktop in Settings, then enter the PC's IP address, username and password in the app. Home editions cannot host RDP. Treat Windows as experimental, and if you try it, send us feedback at bytestudio.rdp@gmail.com, including whether the third screen appeared.

Which Linux desktops work?

The app speaks RDP, so any Linux box with an RDP server can work. Ubuntu with GNOME Remote Desktop is the reference setup we test against. Multi-screen features depend on the host exposing Display Control.

Where does my data go?

The connection goes straight from the headset to your PC. There is no account and no cloud relay. The server certificate is pinned on first use, and the connection credentials stay on the headset, encrypted.

Can I go back to the flat layout after buying Ultra?

Yes. Ultra includes a switch between curved and flat panels. Nothing is locked in one shape.

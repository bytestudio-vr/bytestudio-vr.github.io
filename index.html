    📋 Requirements & Setup

    Hardware Requirements

    • Meta Quest 3 (Developer Mode enabled)
    • Ubuntu PC with GNOME (tested: Ubuntu 26.04)
    • Local network connection (Ethernet + Wi-Fi 5/6 GHz recommended)

    Known Limitations

    • GNOME desktop only (not KDE, XFCE, etc.)
    • Single display support
    • 30 fps max (server limit)
    • No clipboard or file sharing
